计网第一节预习

本文仅仅作为预习，根据慕课和计算机网络课件来的

网络分类（Network classification in size）

个域网PAN（Personal Area Network ）
• 能在便携式消费电器与通信设备之间进行短距离
通信的网络
• 覆盖范围一般在10米半径以内，如蓝牙耳机等（不过看spoc慕课上似乎给出的是小于1m，建议使用这个定义）
➢ 局域网LAN（Local Area Network）（10m到1km）
• 局部地区形成的区域网络，如企业网络
• 分布地区范围有限，可大可小，大到一栋建筑、
小到办公室内的组网
• 电脑WLAN接入，打印机共享等等
➢ 城域网MAN（Metropolitan Area Network ）（10km）
• 范围覆盖一个城市的网络
➢ 广域网WAN（Wide Area Network）（大于10km
• 覆盖很大地理区域，乃至覆盖地区和国家

计算机网络的概念

首先我认为应该先解释一下网络的定义。（这是我的个人理解，当然我们可以看老师的课程回放）我们可以这样描述网络：网络由节点组成，节点之间可以相互传输信息/数据。

计算机网络，顾名思义，就是和计算机相关。那我们首先给出计算机的定义：CPU+MEM+Peripherals（外设，比如鼠标）
这里的MEM是memory的意思
不过，computer本身也是network的一部分，比如说MEM的部分，它作为存储，有SSD这样的物理磁盘存储，也有像云存储这样在网络上的存储，所以现在的computer和network有一点点相互交融的意味，不过我们不做讨论，只记住CPU+MEM+Peripherals这一点即可。现在原始定义比较重要

而我们的computer network的定义是：A colection of autonomous computers
interconnected，这里interconnect不仅仅是链接，而且可以exchange data，autonomous是可以独立自主完成任务Be able to handle independently

（顺便一提，移动手机mobile phone在这里不算computer）

这里顺便一提，协议应该有（这里只是我个人的理解外加AI的一些说法）语法（数据传输的形式，或者说，数据的格式，编码和信号电平），语义（接收信号后有统一的动作，规定通信双方索要表达的含义，指令和应答关系），时序（也就是数据传输的速率和顺序，或者说发送方与接收方的交互节奏，超时重传的时间设定）

CS231n

CS231n笔记1

下面我来梳理一下这个cs321n今天的学习笔记：

第一节关于图像分类与检测问题，我们可以知道图像是由像素组成，也就是说，我们的任务是从图像像素中提取出有用的信息，从而做出准确的分类/判断，完成任务，这对人类来说很简单（比如判断一个图片中的动物是否是猫咪或者狗子），但是作为计算机，其唯一输入就是一个高维向量，也就是图片的像素，显然猫咪这个概念并不存在于像素的向量空间之中，那么就需要一些数学方法进行辅助。

首先我们应该有一个图像，作为哦那关键中的一点（一个高维空间），分类问题中，最常用的办法就是线性分类器，也就是我们使用空间中一个超平面，利用超平面分割空间，然后来把点分割到空间中不同的模块里，这样就是一个简单的分类

现在我们可能需要理清楚的是，我们的模型到底是怎样从像素到语义的（怎么从像素中提取出猫这个本来就不存在的猫概念的）。

早期的方法，是给模型人工规定一些规则，特征，比如，我们规定图片右上角大概多少多少像素范围有一个多少度的锐角（猫耳朵），图片上面拥有灰黑相间的纹路，这种图片就是猫咪这个类别，然而，这样简单的约束显然不能把所有的猫咪都涵盖其中，而且可能会误分类很多其他的图片（比如柴犬），而且图片中的光线/角度/阴影都会影响，所以想要人工规定非常合理的规则是极其困难不可能的，于是我们就需要让机器自己学习其中的规律。

我们所要做的事情就是让模型找到好的权重W，也就是其中的规律，可以准确地分类。

我们以线性分类器为例：

首先我们还是把像素向量展开，放到空间里，然后这个时候，权重W相当于一个模板（它也是一个向量，拥有方向），以二维平面为例，我们可以认为一个与x轴正方向夹角为+45°的权重向量w是一个模板，它代表着“标准的猫”向量，那么我们现在要计算输入的图片X（一个向量）到底是不是猫，然后我们使用向量点积，点积在数学上是|X|.|W|cosα，在几何上，这个值是z在w方向上的分量的长度乘上w的模长，所以这个就可以反应我们这个东西是不是猫

当然这里有一个疑问，为什么不在这个基础上除以w和x的模长，来得出相似度，这样就可以排除模长的影响，这个是线性分类器的一个隐藏问题在这里我们做出了一些假设：

✅ 隐含假设 1
“方向相似 + 模长大 = 更像这个类”

但现实中：

模长大 ≠ 更像猫
可能只是更亮、更近、更占画面
✅ 隐含假设 2
“所有像素贡献是线性可加的”

但现实中的视觉模式：

是局部 + 组合 + 层级
不是简单加权
👉 这正是 CNN 出现的根本原因之一。

2️⃣ 用你刚才的例子来说明
“有图片 A 和 B，我要比较谁更像猫”

如果 A 只是亮度更高 → 点积更大
但语义上 B 更像猫
👉 点积会被模长误导

✅ Cosine similarity 就是在说：

“我只关心方向（特征组合），不关心整体强度

首先，如果我们除以了x与w的模长，也就是只用cosα，这通常适用于比较两个图片和语义的匹配度（相似度），也就是哪一个图片更可能是小猫咪，但是我们要知道，模长本身也可能有一定的信息，比如，他可能是画面更大，更亮，也有可能是信息量更多，也有可能是物体大小，模长可能是噪声，我们不能单纯的把这些可能含有的信息给忽视，尽管它们含有噪声？（这一块我再理解一下），但也有可能不是，在这里，w的意义是：w，“哪些像素位置、颜色、组合值得加分”。
